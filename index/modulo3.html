Antes de dibujar nada

Tres librerías y ya está

En Python hay decenas de librerías para graficar. En la práctica, el 95% del trabajo profesional sale de estas tres, y conviene saber para qué sirve cada una antes de escribir la primera línea.

matplotlibla base

Es el motor: seaborn y pandas dibujan encima de ella. Da el control fino —cada color, cada etiqueta, cada margen— y es la que guarda el archivo para el informe.

ax.bar(x, y)

Si solo aprendes una, que sea esta.

seabornuna línea, un gráfico

Habla DataFrame: le pasas el df y los nombres de las columnas y él agrupa, calcula la estadística y pone la leyenda. Lo que en matplotlib son diez líneas, aquí es una.

sns.boxplot(data=df, x=…, y=…)

Para explorar rápido y para gráficos estadísticos.

plotlyinteractivo

Produce gráficos que se tocan: zoom, valores al pasar el cursor y filtros. No sirve para un PDF, pero es lo que va dentro de un tablero web — el Módulo 4.

px.line(df, x=…, y=…)

Lo retomamos al construir el panel.

y además, según lo que necesites

pandas .plot · el atajo desde el DataFrame plotly express · plotly en una línea altair · gramática de gráficos bokeh · web interactiva plotnine · ggplot2 en Python folium · mapas pyecharts · tableros vistosos

Ninguna es obligatoria. Se aprenden cuando aparece el problema que las pide, no antes.

Y hay una buena noticia: las tres comparten la misma estructura —una figura y unos ejes—. Eso es lo que vemos ahora.
Capítulo 1

Toda gráfica tiene la misma estructura

Una figura es el lienzo; unos ejes son el gráfico que va dentro. Entender esos dos objetos evita casi toda la frustración con matplotlib.

1 Las piezas · pasa el cursor por cada nombre

fig ax ax.bar() set_title() set_xlabel() set_ylabel() tight_layout()

La figura es el lienzo —el tamaño, el fondo y lo que se guarda al exportar—. Los ejes son el gráfico que va dentro: las barras, los rótulos, el título. Casi todo se le pide a ax.

python · el esqueleto 
import matplotlib.pyplot as plt

# 1 · lienzo y ejes
fig, ax = plt.subplots(figsize=(8, 4))

# 2 · dibujar
ax.bar(datos.index, datos.values)

# 3 · explicar
ax.set_title("Ventas por categoría")
ax.set_xlabel("Categoría")
ax.set_ylabel("Millones COP")

# 4 · ajustar y mostrar
plt.tight_layout()
plt.show()

Las cuatro líneas que nunca faltan

set_title()set_xlabel()set_ylabel()tight_layout()

Un gráfico sin títulos de eje no es un gráfico: es un dibujo.

Por internet verás dos estilos: plt.bar(...) y ax.bar(...). Usa el de ax: es el único que funciona cuando pones varias gráficas juntas.

Capítulo 4

El gráfico lo decide la pregunta

No se elige por bonito, sino por lo que quieres que la audiencia responda al mirarlo. Pasa el cursor por cada pregunta; donde haya dos insignias, púlsalas para cambiar el gráfico.

¿Cuál es más grande?

⇆

ax.bar() · ax.pie()

Ordénalas por valor, no alfabéticamente. Cambia a torta y verás lo que cuesta comparar porciones.

pasa el cursor

¿Cómo cambia en el tiempo?

ax.plot(fecha, valor)

Solo si el eje X es tiempo. Para categorías, una línea no significa nada.

pasa el cursor

¿Cómo se reparten?

⇆

ax.hist() · sns.boxplot()

Histograma para una variable; caja para comparar esa variable entre grupos.

pasa el cursor

¿Se relacionan?

⇆

sns.scatterplot() · sns.heatmap()

Dispersión para dos variables; mapa de calor para ver todas las correlaciones de golpe.

pasa el cursor

El gráfico de torta, casi nunca

El ojo humano compara mal los ángulos. Pruébalo aquí arriba: cambia de barras a torta y mira lo que cuesta ordenar las porciones. Resérvala para "una parte frente al total".

La prueba de los cinco segundos

Enseña la gráfica cinco segundos y pregunta qué entendieron. Si dudan, el problema es la gráfica, no la persona.

Capítulo 4 · segunda parte

Cuando la pregunta es más fina

Con los cuatro anteriores resuelves el día a día. Estos cinco aparecen cuando la pregunta se vuelve concreta: rarezas, incertidumbre, varios criterios a la vez, flujos y optimización.

¿Hay datos atípicos?

sns.boxplot(showfliers=True)

Cada punto suelto es una venta fuera de lo normal. Revísala antes de promediar: puede ser un error de captura o el mejor cliente del año.

pasa el cursor

¿La diferencia es real o es ruido?

ax.errorbar(x, media, yerr=ic)

La media sola engaña. Si los intervalos se solapan, no puedes afirmar que un grupo sea mayor que otro.

pasa el cursor

¿Quién gana en varios criterios?

plt.subplot(polar=True) · px.line_polar()

Compara dos o tres perfiles en 5 o 6 ejes. Todos los ejes en la misma escala; con más de siete, se vuelve un garabato.

pasa el cursor

¿Por dónde se mueve el flujo?

go.Sankey() · plotly

De dónde viene y a dónde va: el grosor de la banda es la cantidad. Para embudos, conversiones y reparto de presupuesto.

pasa el cursor

¿Qué combinación da el mejor resultado?

ax.contourf(X, Y, Z) · go.Surface()

Dos variables que puedes ajustar y un resultado que quieres maximizar: el mapa enseña dónde está el óptimo.

pasa el cursor

Con qué se hace cada uno

Las barras de error, la caja con atípicos y la telaraña salen de matplotlib y seaborn. El Sankey y la superficie que se puede girar son terreno de plotly — la librería del Módulo 4.

No los uses por lucirte

Un gráfico raro obliga a la audiencia a aprender a leerlo antes de entender el dato. Solo vale la pena cuando unas barras de verdad no responden la pregunta.

Capítulo 5

Lo que separa un gráfico de una captura

La misma gráfica, los mismos datos. Cinco arreglos de una línea cada uno la convierten en algo que se entiende sin que tú estés al lado explicando. Míralos ocurrir.

una captura lo que sale de matplotlib por defecto
5 pasos · 1 línea de código cada uno · unos 20 segundos
1Un título que afirma, no que describe No "Ventas por categoría", sino "Tecnología concentra el 37% de las ventas": ahorra la explicación.
2Unidades en los ejes Un número sin unidad no es un dato. set_xlabel("millones COP").
3Orden por valor, no alfabético Ordenada se lee el triple de rápido: .sort_values().
4Gris para todo y un color para lo importante Si todas las barras son del mismo tipo, un color por barra no informa: es ruido.
5Fuera lo que no aporta Marco, rejilla y bordes sobrantes compiten con el dato. Nunca 3D ni sombras.
python · los cinco arreglos 
# 3 · ordenar por valor
g = g.sort_values()

# 4 · gris para todas y color solo para la mayor
colores = ["#33415c"] * len(g)
colores[-1] = "#c8f25a"
ax.barh(g.index, g.values, color=colores)

# 1 y 2 · título que afirma y unidades
ax.set_title("Tecnología concentra el 37% de las ventas")
ax.set_xlabel("millones COP")

# 5 · quitar los bordes que no aportan
for lado in ["top", "right"]:
    ax.spines[lado].set_visible(False)
Capítulo 6

Guardar la figura: savefig

plt.show() la muestra y la descarta. Para que quede un archivo hay que pedirlo — y antes de show(), no después.

1 El orden · la misma figura por dos caminos

así sí la figura, en memoria savefig() ventas.png con la gráfica
así no la figura, en memoria show() la muestra y la vacía savefig() ventas.png en blanco

Guardar va primero. show() entrega la figura a la ventana del visor y la deja vacía: lo que se guarde después ya no tiene nada dentro.

2 La resolución · la misma gráfica, dos valores de dpi

Los tres argumentos que importan

dpi=300bbox_inches="tight"transparent=True

dpi es la resolución: 300 para imprimir, 150 basta para pantalla · bbox_inches recorta el margen sobrante · transparent quita el fondo blanco.

python 
from pathlib import Path

SALIDA = Path(__file__).parent / "graficas"
SALIDA.mkdir(exist_ok=True)

fig.savefig(SALIDA / "ventas_categoria.png",
            dpi=300, bbox_inches="tight")

plt.show()   # después de guardar
.png para pegar en documentos. .svg si necesitas ampliarla sin que se pixele: no guarda píxeles, guarda las instrucciones para dibujarla.
Capítulo 7

Un tablero con subplots

Un tablero no es más que varios ejes dentro de una misma figura. plt.subplots(filas, columnas) devuelve una rejilla y dibujas en cada casilla, nombrándola por su fila y su columna.

python · rejilla 3x2 
fig, axes = plt.subplots(3, 2, figsize=(12, 11))

axes[0, 0].barh(g.index, g.values, color="#c8f25a")
axes[0, 0].set_title("Ventas por categoría")

axes[0, 1].hist(df["unidades"], bins=30)
axes[0, 1].set_title("Distribución de unidades")

sns.boxplot(data=df, x="canal_venta", y="margen_pct",
            ax=axes[1, 0])
axes[1, 0].set_title("Margen por canal")

sns.scatterplot(data=df, x="unidades", y="ventas_cop",
                ax=axes[1, 1])
axes[1, 1].set_title("Unidades y ventas")

axes[2, 0].plot(mes.index, mes.values)
axes[2, 0].set_title("Ventas mes a mes")

axes[2, 1].errorbar(ic.index, ic["media"], yerr=ic["err"], fmt="o")
axes[2, 1].set_title("Margen medio y su intervalo")

fig.suptitle("Panel de ventas 2025", fontsize=16)
plt.tight_layout()

Para el conjunto

fig.suptitle()plt.tight_layout()

suptitle titula toda la figura; tight_layout evita que los títulos se pisen.

Esto es un tablero estático: una imagen. En el Módulo 4 lo convertimos en uno interactivo, con filtros y publicado en internet.

Para reutilizar

La plantilla de una gráfica

El mismo esqueleto sirve para cualquier gráfico: cambias la línea que dibuja y los textos. El resto se queda igual.

1 Preparar

grafica.py 
from pathlib import Path
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

BASE   = Path(__file__).parent
SALIDA = BASE / "graficas"
SALIDA.mkdir(exist_ok=True)

df = pd.read_csv(BASE / "datos" / "ventas_empresa.csv")

# ── 1 · el dato que se va a dibujar ──
g = (df.groupby("categoria_producto")["ventas_cop"]
       .sum().sort_values() / 1e6)

# ── 2 · lienzo ──
fig, ax = plt.subplots(figsize=(9, 5))

2 Dibujar, explicar y guardar

grafica.py · continuación 
# ── 3 · dibujar (la única línea que cambias) ──
colores = ["#33415c"] * len(g)
colores[-1] = "#c8f25a"
ax.barh(g.index, g.values, color=colores)

# ── 4 · explicar ──
ax.set_title("Tecnología lidera las ventas de 2025")
ax.set_xlabel("millones COP")
ax.set_ylabel("")
for lado in ["top", "right"]:
    ax.spines[lado].set_visible(False)

# ── 5 · guardar y mostrar ──
plt.tight_layout()
fig.savefig(SALIDA / "ventas.png", dpi=300,
            bbox_inches="tight")
plt.show()
Con tu agente: pégale la plantilla y dile "cámbiame el paso 3 por un boxplot de margen por canal". Al fijar la estructura, el resultado es predecible.
