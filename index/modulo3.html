Capítulo 1

Toda gráfica tiene la misma estructura

Una figura es el lienzo; unos ejes son el gráfico que va dentro. Entender esos dos objetos evita casi toda la frustración con matplotlib.

El lienzo

fig

El tamaño, el fondo y lo que se guarda al exportar.

El gráfico

ax

Las barras, los ejes, el título. Casi todo se le pide a ax.

Las cuatro líneas que nunca faltan

set_title()set_xlabel()set_ylabel()tight_layout()

Un gráfico sin títulos de eje no es un gráfico: es un dibujo.

Por internet verás dos estilos: plt.bar(...) y ax.bar(...). Usa el de ax: es el único que funciona cuando pones varias gráficas juntas.
python · el esqueleto 
import matplotlib.pyplot as plt

# 1 · lienzo y ejes
fig, ax = plt.subplots(figsize=(8, 4))

# 2 · dibujar
ax.bar(datos.index, datos.values)

# 3 · explicar
ax.set_title("Ventas por categoría")
ax.set_xlabel("Categoría")
ax.set_ylabel("Millones COP")

# 4 · ajustar y mostrar
plt.tight_layout()
plt.show()
Capítulo 2

matplotlib: la base de todo

Con tres tipos cubres casi todo: barras para comparar, líneas para el tiempo e histograma para ver cómo se reparten los valores.

1 Barras · comparar categorías

python 
g = (df.groupby("categoria_producto")["ventas_cop"]
       .sum().sort_values() / 1e6)

fig, ax = plt.subplots(figsize=(8, 4))
ax.barh(g.index, g.values, color="#c8f25a")
ax.set_xlabel("millones COP")

2 Histograma · ver la distribución

python 
fig, ax = plt.subplots(figsize=(8, 4))
ax.hist(df["unidades"], bins=30, color="#00f5d4")
ax.set_xlabel("unidades por venta")
ax.set_ylabel("frecuencia")
Mira el histograma: casi todas las ventas son de pocas unidades y hay una cola larga a la derecha. Eso no se ve mirando la tabla.
Capítulo 3

seaborn: una línea, un gráfico

seaborn se apoya en matplotlib pero entiende los DataFrame: le pasas el df y los nombres de las columnas, y calcula el resto.

1 Caja · comparar distribuciones

python 
import seaborn as sns

fig, ax = plt.subplots(figsize=(8, 4))
sns.boxplot(data=df, x="canal_venta",
            y="margen_pct", ax=ax)

2 Dispersión · relacionar dos variables

python 
sns.scatterplot(data=df, x="unidades",
                y="ventas_cop",
                hue="segmento_cliente", ax=ax)
hue= es el argumento más rentable de seaborn: parte cualquier gráfico por una columna categórica y le pone la leyenda solo.
Capítulo 4

El gráfico lo decide la pregunta

No se elige por bonito, sino por lo que quieres que la audiencia responda al mirarlo.

¿Cuál es más grande?

barras

Ordénalas por valor, no alfabéticamente: se leen el triple de rápido.

¿Cómo cambia en el tiempo?

líneas

Solo si el eje X es tiempo. Para categorías, una línea no significa nada.

¿Cómo se reparten?

histogramacaja

Histograma para una variable; caja para comparar esa variable entre grupos.

¿Se relacionan?

dispersióncalor

Dispersión para dos variables numéricas; mapa de calor para ver todas las correlaciones de golpe.

El gráfico de torta, casi nunca

El ojo humano compara mal los ángulos. Con más de tres porciones, unas barras siempre se leen mejor. Resérvala para "una parte frente al total".

La prueba de los cinco segundos

Enseña la gráfica cinco segundos y pregunta qué entendieron. Si dudan, el problema es la gráfica, no la persona.

Capítulo 5

Lo que separa un gráfico de una captura

Dibujar son dos líneas. Las otras cinco son las que hacen que se entienda sin que tú estés al lado explicando.

Siempre

título que afirmaunidades en los ejesorden por valor

El título no debe decir "Ventas por categoría" sino "Tecnología duplica a Papelería". Un título que afirma ahorra la explicación.

Nunca

3Dsombrasun color por barra

Si todas las barras son del mismo tipo, el color no aporta información: solo ruido.

Un color con propósito: gris para todo y un color vivo solo en lo que quieres que miren. Es el truco más eficaz y el más ignorado.
python · resaltar una sola barra 
# gris para todas...
colores = ["#33415c"] * len(g)

# ...y color solo para la mayor
colores[-1] = "#c8f25a"

fig, ax = plt.subplots(figsize=(8, 4))
ax.barh(g.index, g.values, color=colores)

ax.set_title("Tecnología concentra el 38% de las ventas")
ax.set_xlabel("millones COP")

# quitar los bordes que no aportan
for lado in ["top", "right"]:
    ax.spines[lado].set_visible(False)

plt.tight_layout()
Capítulo 6

Guardar la figura: savefig

plt.show() la muestra y la descarta. Para que quede un archivo hay que pedirlo — y antes de show(), no después.

Los tres argumentos que importan

dpi=300bbox_inches="tight"transparent=True

dpi es la resolución: 300 para imprimir, 150 basta para pantalla · bbox_inches recorta el margen sobrante · transparent quita el fondo blanco.

El orden importa

Si pones savefig() después de show(), el archivo sale en blanco: show() ya vació la figura. Guardar va primero.

.png para pegar en documentos. .svg si necesitas ampliarla sin que se pixele.
python 
from pathlib import Path

SALIDA = Path(__file__).parent / "graficas"
SALIDA.mkdir(exist_ok=True)

fig.savefig(SALIDA / "ventas_categoria.png",
            dpi=300, bbox_inches="tight")

plt.show()   # después de guardar
Capítulo 7

Un tablero con subplots

Un tablero no es más que varios ejes dentro de una misma figura. plt.subplots(filas, columnas) devuelve una rejilla y dibujas en cada casilla.

python · rejilla 2x2 
fig, axes = plt.subplots(2, 2, figsize=(12, 7))

axes[0, 0].barh(g.index, g.values, color="#c8f25a")
axes[0, 0].set_title("Ventas por categoría")

axes[0, 1].hist(df["unidades"], bins=30)
axes[0, 1].set_title("Distribución de unidades")

sns.boxplot(data=df, x="canal_venta", y="margen_pct",
            ax=axes[1, 0])
axes[1, 0].set_title("Margen por canal")

sns.scatterplot(data=df, x="unidades", y="ventas_cop",
                ax=axes[1, 1])
axes[1, 1].set_title("Unidades y ventas")

fig.suptitle("Panel de ventas 2025", fontsize=15)
plt.tight_layout()

Cómo se recorre la rejilla

axes[0, 0]axes[1, 1]

Fila y columna, empezando en cero — como los índices de las listas que ya conoces.

Para el conjunto

fig.suptitle()plt.tight_layout()

suptitle titula toda la figura; tight_layout evita que los títulos se pisen.

Para reutilizar

La plantilla de una gráfica

El mismo esqueleto sirve para cualquier gráfico: cambias la línea que dibuja y los textos. El resto se queda igual.

1 Preparar

grafica.py 
from pathlib import Path
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

BASE   = Path(__file__).parent
SALIDA = BASE / "graficas"
SALIDA.mkdir(exist_ok=True)

df = pd.read_csv(BASE / "datos" / "ventas_empresa.csv")

# ── 1 · el dato que se va a dibujar ──
g = (df.groupby("categoria_producto")["ventas_cop"]
       .sum().sort_values() / 1e6)

# ── 2 · lienzo ──
fig, ax = plt.subplots(figsize=(9, 5))

2 Dibujar, explicar y guardar

grafica.py · continuación 
# ── 3 · dibujar (la única línea que cambias) ──
colores = ["#33415c"] * len(g)
colores[-1] = "#c8f25a"
ax.barh(g.index, g.values, color=colores)

# ── 4 · explicar ──
ax.set_title("Tecnología lidera las ventas de 2025")
ax.set_xlabel("millones COP")
ax.set_ylabel("")
for lado in ["top", "right"]:
    ax.spines[lado].set_visible(False)

# ── 5 · guardar y mostrar ──
plt.tight_layout()
fig.savefig(SALIDA / "ventas.png", dpi=300,
            bbox_inches="tight")
plt.show()
